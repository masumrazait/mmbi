# 🏦 Mannat Bank

**Mannat Bank** is a modern fintech web application that offers a seamless, secure, and user-friendly digital banking experience. With modules like account management, fund transfers, bill payments, investments, and budgeting, it helps users manage finances smartly and efficiently.

---

## ✨ Key Features

- 👋 **Personalized Dashboard** — Welcomes the user with a clean, intuitive interface.
- 💳 **Accounts Overview** — View savings and fixed deposit balances at a glance.
- 💸 **Fund Management** — Transfer funds and pay bills with ease.
- 📈 **Investments & Budgeting** — Track investments and plan monthly budgets.
- 🔔 **Real-time Alerts** — Get notified of recent transactions and account activity.
- 🧾 **Transaction History & Statements**
- 🧍 **Secure Profile Management & KYC**
